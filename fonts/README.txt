Add the Montserrat font file here.
1. Open https://fonts.google.com/specimen/Montserrat and choose Download family.
2. From the zip, copy Montserrat-VariableFont_wght.ttf into this folder.
Montserrat is open source (SIL Open Font License), so it can be hosted with the site.
Until the file is added, the page loads Montserrat from Google Fonts instead.
